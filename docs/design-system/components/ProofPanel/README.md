ProofPanel shows whether one Call is proven against the on-chain root.

## Use
Use it on the Call receipt page.

## Provide
Provide the verdict, Call ID, on-chain root, Payee, settlement transaction, checks and explorer URL.

## Rules
Lead with the verdict: verified, waiting or does not verify.
Wrap every ID and offer copy.
Link to the NEAR explorer with a 44px target.
List the checks that earn the verdict.
Use `on-semantic` on solid seals.

## Do and do not
Do say "Anyone can repeat this check."
Do not show verified until every check passes.
