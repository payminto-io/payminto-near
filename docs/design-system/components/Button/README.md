Button triggers one action, in six variants and touch sizes.

## Use
Use `primary` once per view for the main action, and `outline` or `secondary` for the rest.
Use `destructive` only for actions that stop or remove something.
Use `link` for navigation inside text.

## Provide
Provide a verb-first label, a `variant`, a `size`, and an optional 16px lucide icon.

## Sizes
Default is 36px, `sm` 32px and `lg` 40px.
Below 768px use the 44px `touch` size and the 48px `pay` size, both with `radius-xl`.

## Do and do not
Do name the object: "Stop this Budget".
Do not put two `primary` buttons side by side.
Do pair `destructive` with `destructive-foreground`; in dark that is dark text on the lightened fill, never white.
