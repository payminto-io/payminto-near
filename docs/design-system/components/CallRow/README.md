CallRow is one Call in a ledger: who paid whom, for what, its status and the exact amount.

## Use
Use it for Call lists at every width; it replaces Table below 768px.

## Provide
Provide time, agent, Payee, Budget name or Refusal reason, status, amount and a link.

## Rules
Wide rows use five columns.
Narrow rows use two lines, at least 64px tall, with the whole row as the target.
On a refused row show the reason in place of the Budget.
Names truncate; amounts never do.

## Do and do not
Do link the row to the Call detail.
Do not put extra buttons in a row on phones.
