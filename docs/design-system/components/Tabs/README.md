Tabs switch between views of the same object.

## Use
Use `default` inside panels and `line` at page level.

## Provide
Provide two to five short labels and one panel for each.

## Mobile
Use the 44px track below 768px and let it scroll sideways instead of wrapping.

## Do and do not
Do keep keyboard arrows working, as the Radix parts do.
Do not use Tabs to trigger actions.
