BatchSummary shows how N Calls settled as M USDC transfers.

## Use
Use it on Settlement batch pages and before starting a settlement.

## Provide
Provide the Call count, gross amount, transfer count, net amount, the transfers, and the batch link.

## Rules
Draw one tick per Call, capped at 120 with a "+N" count.
Draw one wide bar per transfer.
Stack with a downward arrow below 620px.
Ticks are decorative and hidden from assistive technology, so state the counts in text.

## Do and do not
Do show exact amounts on both sides.
Do not present the ratio without the counts.
