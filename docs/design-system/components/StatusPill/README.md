StatusPill states whether a Call is settled, waiting or refused, and has no other values.

## Use
Use it wherever a Call or transfer appears.

## Provide
Provide `status`: `settled`, `waiting` or `refused`.

## Rules
Height is 22px, with a 6px dot and a 12px medium word.
All three pairs pass 4.5:1 in both themes.

## Do and do not
Do keep the word; colour alone is not enough.
Do not add a fourth value or reuse these colours for other meanings.
