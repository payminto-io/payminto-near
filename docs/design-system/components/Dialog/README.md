Dialog asks for a single decision in the center of a wide screen.

## Use
Use it from 640px for confirming an action such as stopping a Budget.
Below 640px use Sheet.

## Provide
Provide a question as title, one to three sentences on the effect, and two buttons.

## Rules
Max width is 512px, padding 24px, `radius-lg`, on `overlay`.
Focus is trapped and Escape closes, except during submission.

## Do and do not
Do say what stays true, such as "Settled Calls stay settled."
Do not stack Dialogs.
