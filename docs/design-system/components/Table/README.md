Table is the dense ledger for wide screens, with status filters above it.

## Use
Use it from 768px for Calls, Refusals and Settlement batches.
Below 768px render CallRow instead.

## Provide
Provide columns, rows and filter state.
Right-align Amount columns and set times and account IDs in mono.

## Rules
Rows are 14px with 8px cell padding and a 40px head.
Filter by status first; the selected chip uses `accent`.

## Do and do not
Do keep the status word in each row.
Do not truncate amounts.
